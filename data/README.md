# 看板数据编辑指南(给团队)

本目录下的 JSON 文件是销售看板的数据源。**在这里改完保存,约1分钟后看板自动更新**,不需要找白猫。

## 各文件对应看板哪个模块

| 文件 | 看板模块 |
|---|---|
| `tasks.json` | 📌 任务待办 |
| `sample_plan.json` | 🧪 样品计划(首页项目看板内) |
| `orders.json` | 📅 月拉动计划 |
| `orders_data.json` | 📋 订单台账 |
| `finance.json` | 💰 对账开票 |
| `projects.json` | 🚀 项目管理 / 🏠 项目看板 |
| `non2026.json` | 📦 非26年量产项目 |

## 怎么改(以任务待办为例)

1. 打开本仓库页面 → 点 `data/tasks.json`
2. 点右上角 ✏️(铅笔图标)进入编辑
3. 找到要改的那一行,修改内容(见下方字段说明)
4. 点绿色 **Commit changes** → 直接点 Commit changes(不用填别的)
5. 等约 1 分钟,刷新看板即可看到

## 常用字段说明

**任务(tasks.json)每条包含:**
- `id`: 任务编号(不要改,如 T011)
- `title`: 任务标题
- `priority`: **P0**(紧急)/ P1(重要)/ P2(常规)/ P3(低优)
- `status`: **todo**(待办)/ doing(进行中)/ done(已完成)
- `due`: 截止日期,格式 `"2026-09-10"`,不填则空 `""`
- `remark`: 备注

**样品计划(sample_plan.json)每条包含:**
- `project`: 项目名
- `part`: 零件名
- `qty`: 件数(数字,不带引号)
- `makeType`: "make"=自制 / "out"=外协
- `supplier`: 供应商
- `stage`: 样品状态:**planning**(待打样)/ making(打样中)/ to_send(待送样)/ sent(已送样)/ confirming(客户确认中)/ confirmed(样品确认)/ rejected(退回重打)
- `planDate`: 计划送样日期 `"2026-09-15"`,未定留 `""`

## ⚠️ 注意

- **逗号和引号必须英文**(`"` 和 `,`),中文逗号会报错
- 每条记录之间用英文逗号 `,` 分隔,**最后一条后面不要加逗号**
- 改完可以点 **Preview changes** 预览,绿色+号是新增、红色-号是删除
- 改错了也没关系:白猫每天自动检查两边一致性,或者直接告诉我帮你恢复
- 所有金额/价格为**未税人民币**口径

## 出错了怎么办

- 如果页面报错/看板显示异常:把改过的文件发我,我帮你修复
- 想新增一条记录:复制一条已有的,改内容,注意前后逗号
